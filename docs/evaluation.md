# Evaluation

Evaluation work begins in Phase 7. The common `MemorySystem` result already reserves white-box fields for retrieved IDs, scopes, component scores, temporal validity, provenance, traversal paths, latency, and token counts. Planned metrics are answer accuracy, Precision@K, Recall@K, Cross-Scope Contamination Rate, stale-memory error rate, correction relapse, p50/p95 latency, context tokens, storage overhead, and write cost. No performance results have been generated in Phase 1.
